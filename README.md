# TaskMaster - Modern To-Do App

A clean, responsive, and feature-rich To-Do web application built with vanilla HTML5, CSS3, and JavaScript.

## ✨ Features

- **Add & Delete Tasks**: Effortlessly add new tasks and delete unwanted tasks with smooth exit animations.
- **Inline Task Editing**: Edit existing tasks on the fly (click the edit button or double-click the task). Supports `Enter` to save and `Escape` to cancel.
- **Task Status Toggle**: Mark tasks as completed or active with custom animated checkboxes.
- **Task Filtering**: Filter your view by:
  - **All**: Displays all tasks.
  - **Pending**: Shows only active, uncompleted tasks.
  - **Completed**: Shows finished tasks.
  - Interactive counter badges update in real-time.
- **Dark Mode**: Seamless toggle between clean light theme and sleek dark mode, respecting both your preference and system settings.
- **Local Storage Persistence**: All your tasks, completion states, and theme choices are automatically saved locally in your browser.
- **Clear Completed**: Quick action to purge finished tasks in a single click.

## 🚀 How to Deploy to GitHub Pages

Because `index.html` is now located in the root of the repository, deploying is 100% free and takes 30 seconds:

1. Commit and push your changes to GitHub:
   ```bash
   git add .
   git commit -m "Add modern UI, edit/delete, filters, dark mode, and index.html"
   git push origin main
   ```
2. Open your repository on GitHub: [omkar2526-alt/ToDo-App](https://github.com/omkar2526-alt/ToDo-App)
3. Go to **Settings** > **Pages** (in the left sidebar).
4. Under **Build and deployment** > **Branch**:
   - Select `main`
   - Select `/ (root)`
   - Click **Save**.
5. In 1–2 minutes, your site will be live at:
   `https://omkar2526-alt.github.io/ToDo-App/`
